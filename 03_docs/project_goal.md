# 项目目标

## 项目名称

HB-RABS-3D-Reconstruction

## 项目目标

基于 RABS 分装间生产视频和参考截图，从零制作一个**高保真、可交互的 Three.js 3D 网页场景**，用于复刻舱体内部的生产仪器、工作台、手套孔、玻璃、漏斗、罐体、管路、法兰、卡箍、工具、垫片和气流效果。

## 范围

### 包含

- RABS 舱体主体结构（外壳、玻璃面板、后壁）
- 工作台面
- 手套孔/手套端口
- 中央漏斗及罐体
- 右侧罐体及设备
- 后壁端口及管路系统
- 法兰、卡箍、垫片等连接件
- 小型工具及零件
- 气流/烟雾视觉效果（可选增强）
- 灯光与摄像机视角

### 不包含

- 工业 CAD 级精确尺寸逆向
- 物理仿真（流体、粒子精确模拟）
- 后端服务或数据库
- 移动端原生 App

## 核心约束

1. **禁止复用旧项目**：不得参考、复制或导入任何旧 Blender、GLB、OBJ、HTML 或其他模型文件
2. **从零开始**：所有模型和代码均在本项目中新建
3. **Three.js 优先**：建模以 Three.js 网页预览为主要输出形式
4. **高保真交互**：最终场景应支持旋转、缩放、平移，关键区域可点击高亮
5. **视频视觉一致**：目标是与参考视频/截图视觉上高度一致，而非工业 CAD 级精度

## 输出形式

- 可独立打开的 Three.js HTML 页面（无需构建工具）
- 可通过 `npx serve` 或直接双击在浏览器中查看
- 后续阶段可选迁移至 Vite/Next.js 工程化结构
