# 统一坐标系

## 轴定义

| 轴 | 方向 | 正方向 | 负方向 |
|----|------|--------|--------|
| X | 左右 | 右 | 左 |
| Y | 上下 | 上 | 下 |
| Z | 前后 | 靠近观察者（前） | 靠近后壁（后） |

## 原点

- 原点暂定为**工作台中心位置**
- 位于中央漏斗/罐体轴线附近
- 具体坐标原点将在建模第一个对象时确认并记录

## 单位

- 当前使用**视觉建模单位**（1 unit = 视觉上的合理尺寸）
- **不声明为毫米级真实尺寸**
- 所有对象比例以视频/截图中相对关系为准
- 后续如需精确尺寸，可全局缩放

## 视图与朝向

### 默认相机

- 默认相机位于舱体正前方略高处
- 初始位置参考：`camera.position.set(0, 2, 15)`
- 视角中心对准原点（工作台面中心）

### 各方向约定

```
         +Y (上)
          |
          |
          |
          +---------> +X (右)
         /
        /
       /
      v  +Z (靠近观察者)
```

- **前视图**：从 +Z 方向看向原点（观察者视角）
- **后视图**：从 -Z 方向看向原点（后壁方向）
- **左视图**：从 -X 方向看向原点
- **右视图**：从 +X 方向看向原点
- **顶视图**：从 +Y 方向看向原点

## 旋转约定

- Three.js 默认右手坐标系
- 旋转顺序：`'YXZ'`（除非特殊需要）
- 弧度制，文档记录时附带角度制注释

## 对象默认朝前

- 对象默认"正面"朝向 +Z（观察者）
- 管道默认沿 Y 轴或 Z 轴延伸
- 法兰平面默认平行于 XZ 平面（水平法兰）或 YZ 平面（垂直法兰）
